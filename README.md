# AI Operations Command Center

## Overview
AI Operations Command Center is a full-stack applied AI automation platform that combines a frontend dashboard, Flask backend, database logging, API endpoints, job intelligence, email intelligence, and Make.com-ready automation routes.

This project demonstrates how AI workflows can be centralized into a business operations dashboard for automation, monitoring, and API-driven workflows.
